# M3: imported Final Destination match

```
cargo run -p melee-sim -- run harness/scenarios/idle_fd_fox.toml --out /tmp/idle_fd_fox.actual.jsonl
cargo run -p melee-sim -- gate harness/scenarios/idle_fd_fox.toml
```

The gate compares 600 records with exactly 49 schema keys each, using
`melee-diff`'s bit-pattern equality. Output is `600 ticks, 49 keys, 0
divergences`, or the first differing frame, phase, key and expected/actual
bits, with the tick's RNG-writing procs. `approx` is a display hint; additional
oracle metadata (`tick`, etc.) is not part of a canonical `Record`.

## Scheduler and the first tick

`World::new(WorldConfig::MELEE)` owns real GObjs/procs. The FD proc table is
registered with its p_link/s_link/p_priority values, followed by two fighter
GObjs (p_link 8, priority 0), and main/aux effects (s_link 15, p_link 11/12,
priority 1). Each map's Ground wrapper and separate stage callback share one
GObj, retaining registration order. World orders phases, object links and
creation order, so P0 runs before P1 within each fighter phase. No hand-sorted
per-tick event list replaces World. No changes to hsd-gobj were needed.

Callbacks share owned scene state through `Rc<RefCell<_>>`; its borrow lasts
only for one proc. This meets World's existing closure interface without a
cross-layer Melee dependency. World remains available to callbacks for future
item creation/removal. The fake-proc tests exercise the complete registered
FD spine and verify an item created during fighter physics runs its physics
and collision in that same tick, but its earlier status phase next tick.

**The actual savestate stops inside P0's ProcessHit at s_link 14.** Import
checks the saved scheduler phase (`HSD_GObj_804D7834`), current proc
(`HSD_GObj_804D7838`), callback 0x8006D1EC and owning P0 GObj. Thus both fighters'
animation/physics already match completed tick record 0, while the particles
have not run. The first scheduler pass suppresses completed phases below 14,
finishes P0 ProcessHit, runs P1 ProcessHit, particles, dynamics, camera and
player mirrors, then emits ordinal 0. P0's idle ProcessHit only rebuilds
hurtbox caches; re-entering that partial proc is idempotent and consumes no RNG.
All subsequent calls run the entire registered spine. This is 600 completed
observations: one partial-tick completion plus 599 full ticks, not 600 extra
animation advances from the saved fighter pose. A different resume point is
rejected, not approximated.

The seed before the first particle pass is 1286746018 (`0x4CB22FA2`). The
scenario's `seed = 1` is for cold starts and does not override a saved match.
The stage's saved oscillator state produces three rare calls through
`FinalDestination::run_stage_proc` / `BackgroundMotion::tick`:

| Ordinal | Branch | Event |
|---|---|---|
| 109 | grLast_8021ADD0+0x270 / 0x8021B040 | Negative yaw limit |
| 196 | grLast_8021ADD0+0x13C / 0x8021AF0C | Negative pitch limit |
| 509 | grLast_8021ADD0+0x22C / 0x8021AFFC | Positive yaw limit |

These ordinals are verification results, not scheduling inputs. All nine
fighter Wait choices and all particle draws consume the same evolving RNG.
The final seed is `0x72AA79F8`. No per-tick seed, draw count, choice or future
state is fed into the simulation.

## InitialState: imported versus computed

`InitialState::from_savestate_traces` is the sole boundary adapter. It reads
only the first fighter ledger/expected line and the initial particle record
and metadata, plus the owned Dolphin savestate. Later expected rows are read
only by the comparison layer. No ledger RNG draws are consulted.

| Imported | Source |
|---|---|
| Fighter position/facing/damage, velocities and ground state, jumps, animation ID/time/rate/remainder/blend progress | Frame-zero raw fighter ledger, checked against the canonical frame-zero fighter fields |
| Input histories/button timers, all seven CPU fields, shield and nametag state, ground-pose flags, thrown capsule current/previous position, disabled dynamics sentinel | Same initial raw boundary; adapter follows melee-ft/tests/fighter_support |
| Command PC/timer/frame and empty return stack | Initial ledger; absolute PC resolves to an owned command index using the archive motion-table base |
| Full CollData floor/contact/ECB and previous-frame history, lock/teeter flags | Initial raw Fighter; collision bone references resolve from archive descriptors |
| Main and blend skeleton SRT, flags, cached matrices, accumulated scale and runtime part flags | LZ4 Dolphin savestate, with MEM1 located and verified against the saved Fighter prefix and animation scalars |
| FD live maps/creation order, controller phase/elapsed/start/demo/transition/fade-complete flags | Actual p_link-5 GObjs and Ground user data in saved MEM1 |
| FD pitch/yaw, both speeds, both accelerations, amplitude and generator presence | Saved map 7 Ground+0xC4..0xE0; not inferred from later draw ticks |
| Every canonical live generator/particle field, list order, family allocator and associations | particles.jsonl.initial.jsonl; adapter follows hsd-particle/tests/support/restore.rs and rejects unmapped fields through a full round trip |
| Particle generator's cached attachment matrix | Initial metadata, resolved by its JObj pointer |
| Shared RNG seed and partial-tick scheduler location | Saved MEM1, cross-checked with particle initial record/metadata |

Computed or reconstructed:

- Attributes, Fox hooks, common data, command programs, Wait motions and
  weights, part/bone descriptors and animation tracks come from `PlFx.dat`,
  `PlFxAJ.dat`, `PlCo.dat`, `PlFxNr.dat` and **`PlFxOr.dat`**. P1's saved costume
  is orange and has different rest transforms; it cannot reuse P0's skeleton.
- Typed fighter ownership, callbacks, part mappings and inactive idle defaults
  come from `Fighter::prepare`; cold spawn/CPU RNG is never rerun. Archive
  animation evaluation reconstructs playback cursors; saved transforms/caches
  then replace the evaluated pose, as in the existing fighter reference test.
- Static collision is loaded from `GrNLa.dat` via melee-gr/melee-mp.
  `FinalDestination::initialize` supplies typed defaults using a private
  scratch RNG, then saved controller/oscillator state replaces runtime values.
- Particle program bytes, descriptor creation parameters and texture metadata
  come from the GrNLa bank. Temporary generator construction uses a private
  scratch RNG; all captured runtime fields overwrite its values. Internal IDs
  follow saved list order, traversal cursor starts empty, capacity is unlimited
  as in the reference replay. No allocation or creation draw touches the shared
  restored RNG.
- Hurtbox/dynamics/camera caches and Player mirrors are computed by the fighter
  procs. General camera motion/zoom is not part of this 49-key gate.

## Scope and guards

This is the two-human, neutral-input FD M3 slice. Other stages/characters,
inputs, extra fighters, unrecognized TOML fields, incompatible saved phase,
non-sphere/AppSRT/callback particles and pending detaches are rejected. Existing
fighter procs reject unsupported interaction/action paths.

FD Ground wrappers retain scheduler registrations but perform no additional
work in this slice: light/GX animation outputs are not simulated; the disabled
spawn-manager/rain paths and static collision need no updates. FD map 4's
animation-0 particle attachment is stationary over this interval, and its
creation key has already run. The live generator is restored rather than
created a second time. The constructor requires LayeredStart, no transition,
completed fade, zero tilt amplitude and no tilt generator, and limits the run
to the pre-transition interval. New StageActions fail explicitly. General
stage animation/material transitions, animated particle attachments, HUD,
match bookkeeping and camera rendering remain outside this gate. None of
those are silently represented as a general implementation.

No accessor/proc-table changes were required in melee-ft, melee-gr,
hsd-particle or hsd-gobj. JSON/LZ4 adapters live in melee-sim, retaining the
lower crates' dependency boundaries. Tests skip only if required local files
are absent; malformed or inconsistent present fixtures fail.
